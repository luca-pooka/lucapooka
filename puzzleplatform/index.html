Update Log

1.2 - 10/13/25

  • Added levels 7-8
  • Added semisolid blocks
  • Added lightning which you cannot go through but can throw boxes through
  • Changed how the player's movement works, now it is more physics based
  • Fixed how you would always fall down slopes with the new physics based movement
  • Made it so when boxes are picked up they still have a hitbox so they can't clip into blocks while you are holding them
  • Changed how the conveyor belts work again, they were way too fast before
  • Fixed a bug where the blue button wouldn't look pressed down when it was
  • Other fixes and changes

1.1 - 10/2/25

  • Added levels 5-6
  • Added levers to switch the on off blocks
  • Made the player thinner so they can fit between one block gaps
  • Changed and fixed how players move on conveyor belts
  • Made it so the boxes can bounce off of the bouncy blocks and move on conveyor belts
  • Fixed a bug where you sometimes wouldn't die if you touched spikes
  • Slightly changed the boxes hitboxes so they shouldn't get stuck as much in one block gaps
  • Added an idle animation
  • Removed the falling animation (i didn't like it)
  • Other fixes and changes

1.0 - 9/28/25

  • Added main mode with the first four levels (levels subject to change)
  • Added half blocks
  • Made it so you can restart the level by holding the R key
  • Changed it so you can only crouch while on the ground and cannot pick up a box while crouching
  • Fixed a bug where you could fall off of a platform and still be able to jump
  • Fixed a bug where having multiple of the same colored buttons wouldn't work properly
  • Fixed a bug where if you try to throw a box while touching a different box the box would get stuck in midair
  • Fixed a bug where you wouldn't be able to see the colors of the buttons/on off blocks before placing them down in the editor
  • Other fixes and changes
